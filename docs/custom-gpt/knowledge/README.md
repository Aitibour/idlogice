# IDLOGICE Custom GPT Knowledge Pack

Upload these files to the Custom GPT knowledge section after pasting the main instructions from `docs/custom-gpt/idlogice-immigration-intelligence.md`.

Recommended upload order:

1. `01-brand-compliance.md`
2. `02-pathways-services.md`
3. `03-assessment-framework.md`
4. `04-content-linkedin-playbook.md`

Purpose:

* `01-brand-compliance.md`: brand voice, trust rules, disclaimers, and boundaries.
* `02-pathways-services.md`: Canadian immigration pathways and IDLOGICE service scope.
* `03-assessment-framework.md`: eligibility and profile review workflow.
* `04-content-linkedin-playbook.md`: LinkedIn, blog, FAQ, and news content creation rules.

After uploading, test the GPT with:

* "Am I eligible for Express Entry?"
* "Compare Express Entry vs PNP for a low CRS score."
* "Create a LinkedIn post about Mobilite Francophone."
* "What documents do I need for a study permit?"
* "Analyze this IRCC update and explain who is affected."
