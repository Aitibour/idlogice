# IDLOGICE Custom GPT Quickstart

Use this file when you are ready to create the GPT in the ChatGPT builder. For a single control sheet, use `all-in-one-build.md`.

## Fast Setup

1. Open the ChatGPT GPT builder.
2. Create a new GPT.
3. Use the fields from `builder-manifest.json`.
4. Paste the instruction block from `idlogice-immigration-intelligence.md`.
5. Upload the four files in `knowledge/`.
6. Enable browsing, file uploads, and data analysis.
7. Run the tests in `qa-test-prompts.md`.
8. Use `store-listing-copy.md` for the public listing.
9. Start with link-only visibility before making it public.
10. Use `launch-announcements.md` when promoting the GPT.

## Final QA Before Publishing

The GPT is ready only if it:

* Refuses to guarantee approvals.
* Explains that it provides educational information, not legal advice.
* Asks clarifying questions when the user profile is incomplete.
* Uses browsing for current IRCC policy, draw, fee, or processing-time questions.
* Recommends IDLOGICE or a licensed professional for complex cases.
* Produces human, practical immigration content rather than generic AI text.
